QUÉ CAMBIÓ
1. Al abrir el enlace publicado aparece una invitación con su logo:
   «Instalar MAUZI NOTE» y «Continuar en el navegador».
   No obliga a instalar ni a vincular Google para usar la aplicación.
2. La invitación y las entradas para instalar se ocultan al abrir la PWA desde
   su icono, cuando el navegador confirma la instalación o cuando puede detectar
   una instalación existente. No se confunde «Solo nota / pantalla completa» con
   una instalación. Cerrar o rechazar el aviso no marca falsamente la app instalada.
3. Quitado el diccionario: seleccionar palabras no abre definiciones, buscadores,
   fuentes ni otras pestañas. Las citas y las Biblias integradas siguen disponibles.
4. Doble toque o doble clic para seleccionar una palabra. Se puede ampliar la
   selección y conservarla al pasar al botón Formato para aplicar negrita o color.
5. El modo Formato mantiene el contenido sin teclado; el lápiz sigue activando
   el modo Escribir. El formato conserva párrafos, listas y numeración romana.

CÓMO USAR LA SELECCIÓN
- Abra una nota. Haga doble toque (celular) o doble clic (PC) sobre una palabra.
- Amplíe con los tiradores de selección del dispositivo, el ratón o el teclado.
- Toque el icono de Formato de la barra superior. La selección se conserva.
- Aplique Negrita, Color del texto o resaltado y confirme la nota con ✓.
Los gestos y tiradores nativos dependen del navegador: algunos teléfonos utilizan
una pulsación prolongada para mostrar la selección. La app no bloquea ese gesto.
El modo Escribir se conserva para editar el contenido con el teclado.

INSTALACIÓN: LO QUE HACE EL NAVEGADOR
La invitación de MAUZI NOTE aparece automáticamente en un acceso web nuevo,
salvo que ya se detecte instalada. El cuadro oficial de instalación requiere
que la persona pulse el botón y confirme; no se fuerza sin consentimiento.
En Chrome/Edge compatibles se utiliza el aviso nativo cuando está disponible.
En iPhone se muestra dentro del cuadro: Safari → Compartir → Añadir a pantalla
de inicio → Abrir como app web, si aparece → Añadir.
Si el enlace se abre en una vista interna de otra app, se indica abrirlo en
Chrome o Safari. Se puede continuar en el navegador sin instalar.
No todos los navegadores permiten saber si se instaló desde OTRO navegador o
perfil. Abrir desde el icono instalado sí permite ocultar el aviso. No se promete
una detección universal entre perfiles distintos. Si se borran los datos del
sitio o se desinstala, el navegador puede volver a ofrecer la instalación.
Espere «Lista sin conexión» antes de usar la app sin internet.

QUÉ SUBIR A GITHUB
1. Guarde cualquier nota abierta y haga una copia desde Mi cuenta → Guardar copia.
   NUNCA suba ese respaldo personal de notas al repositorio público.
2. Descomprima TODO el ZIP en su carpeta local de MAUZI NOTE. Acepte reemplazar
   los archivos del mismo nombre y conserve la carpeta icons con sus imágenes.
3. En el MISMO repositorio rulymauzi-byte/MAUZI-NOTE:
   Add file → Upload files → suba TODO el contenido descomprimido → Commit changes.
   index.html debe quedar directamente en la raíz, no dentro de otra carpeta.
   No suba únicamente el ZIP cerrado. No borre otros archivos del repositorio.
4. Cuando GitHub termine de publicar, actualice PC, celular y tablet:
   Mi cuenta → Estado de la aplicación / actualizaciones → Aplicar actualización.
   Guarde cualquier edición antes de actualizar. Debe indicar la versión 4.7.
