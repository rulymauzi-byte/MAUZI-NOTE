Conectar tu cuenta a la nube

Para usuarios

  1. Envía tu correo Google al administrador por WhatsApp (+502 5848 4682) y espera su confirmación.
  2. En MAUZI NOTE abre Mi cuenta → Conectar mi correo con Google y elige ese mismo correo.
  3. Espera a ver «Guardado en la nube ✓». Desde ese momento tus notas llegan solas a tus otros equipos con la misma cuenta.

La sesión queda abierta en el dispositivo: ya no vence cada semana. Si usabas la versión anterior (Google Drive), conecta la misma cuenta: las notas guardadas en este dispositivo se pasan solas a la nube.

Si aparece «Tu correo aún no está validado», el administrador todavía no lo agregó. Puedes seguir usando la app sin cuenta mientras tanto.

Para el administrador (proyecto Firebase «MauziNote»)

  1. Authentication → Sign-in method → Google → Habilitar.
  2. Authentication → Configuración → Dominios autorizados → agregar rulymauzi-byte.github.io.
  3. Firestore Database → Crear base de datos (modo producción) y en Reglas pegar el contenido de firestore.rules → Publicar.
  4. Pegar la configuración de la app web en firebase-config.js y subir los archivos a GitHub.

Validar a una persona

Firestore Database → Datos → Iniciar colección (solo la primera vez) con ID permitidos. Luego Agregar documento:

ID del documento:  correo en minúsculas, por ejemplo  juan@gmail.com
Campo:             nombre   (string)   Juan

Para quitar el acceso, borra ese documento. No hay límite de 100 usuarios ni vencimiento a los 7 días.

¿Abrir la app a cualquier cuenta Google sin validar? En firestore.rules cambia return estaPermitido(); por return true; y publica.

Plan gratuito (Spark)

Incluye 1 GiB de datos, 50 000 lecturas y 20 000 escrituras al día. Las imágenes ocupan espacio dentro de las notas; si el límite diario se alcanza, los cambios se quedan en el dispositivo y se envían al día siguiente.
