========================================

ALCANCE
Se ejecutó el HTML, estilos y código reales en Chromium mediante Playwright.
El navegador administrado de este entorno bloqueó la navegación con
ERR_BLOCKED_BY_ADMINISTRATOR. Las pruebas se realizaron mediante set_content,
con un adaptador externo al paquete para dirección HTTPS, almacenamiento
local/IndexedDB, identidad y respuestas de Google Drive.
No se cambiaron las políticas del navegador. El adaptador NO se entrega.

Las pruebas de disposición usan anchos de 320, 360, 390, 768, 1440 y 1920 píxeles.
La selección, modales y botones operan sobre DOM real; el almacenamiento y Drive
son simulados. No se accedió a una cuenta real, no se eliminó contenido real de
Google ni se modificó el repositorio. No se probó instalación real, service worker
real o gestos de un teléfono físico. Las pruebas no garantizan disponibilidad,
permisos vigentes ni velocidad del servidor de Google.
