MAUZI NOTE 5.0 · ACCESO DE USUARIOS
==================================
Desde la versión 5.0 YA NO se valida a nadie por WhatsApp.
Cada persona entra con su propio correo de Google, igual que la app del maratón.
Las reglas de Firestore (firestore.rules) hacen que cada cuenta solo vea sus notas.

QUITAR EL ACCESO A ALGUIEN
- Firebase → Authentication → Usuarios → busque el correo → menú ⋮ → Inhabilitar cuenta.

BORRAR UNA CUENTA COMPLETA (si un usuario lo pide)
- Firestore → users → busque el documento cuyo campo email sea su correo.
  Borre sus subcolecciones (notes, meta, modules) y después el documento.
- Authentication → Usuarios → buscar el correo → Eliminar cuenta.

La colección "permitidos" que se creó antes ya no se usa; puede borrarla.
